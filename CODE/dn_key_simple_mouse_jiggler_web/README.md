# DN-KEY Simple Mouse Jiggler with Web Interface

This is the **2025 sample code** that ships with DN-KEY devices for general use. It's a simple, clean example that demonstrates basic DN-KEY functionality.

## What it does:

- **Mouse Jiggler**: Random mouse movements to prevent screen lock/sleep
- **Web Interface**: Simple web server to toggle jiggling on/off
- **LED Status**: Breathing effect with status feedback
- **Touch Controls**: Use the DN logo to toggle jiggling
- **WiFi Access Point**: Creates its own network for web control

## Features:

- Simple mouse jiggling with random movement
- Web interface accessible via device's WiFi network
- LED breathing effect with status feedback
- Touch control via DN logo
- Clean, commented code for learning
- Perfect starting point for modifications

## Usage:

1. **Copy to device**: Copy `code.py` to your DN-KEY device
2. **Connect to WiFi**: Device creates network "dn_key" (password: 12345678)
3. **Web control**: Visit `http://192.168.4.1` in browser
4. **Touch control**: Tap the DN logo to toggle jiggling
5. **LED feedback**: 
   - Blue breathing = idle
   - Green = jiggling active
   - Red = error
